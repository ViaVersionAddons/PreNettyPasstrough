PreNettyPasstrough
================

PreNettyPasstrough is a fork of the [ProtocolSupportBungee](https://github.com/ProtocolSupport/ProtocolSupportBungee) Plugin that adds Support for 1.6, 1.5, 1.4, 1.3, 1.2, 1.1 and 1.0 clients on BungeeCord<br>

Important notes:
* Only latest version of this plugin is supported
* This plugin can't be reloaded or loaded not at BungeeCord startup

---

PreNettyPasstrough is (as the Name already says) a passthrough protocol plugin, not a converter, so servers behind BungeeCord should also support those versions using something like [ViaPreNetty](https://github.com/ViaVersionAddons/ViaPreNetty) or [ProtocolSupport](https://modrinth.com/plugin/protocolsupport)

Also servers behind Bungeecord should support https://github.com/ProtocolSupport/ProtocolSupport/wiki/Encapsulation-Protocol

The preferred setup is to put ProtocolSupport to all servers behind BungeeCord
